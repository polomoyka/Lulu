# Lulu

Lulu is a SaaS-based retail management system designed to simplify store operations, inventory management, sales tracking, and analytics.

## Features

* Product and category management
* Sales tracking
* Store management
* Supplier management
* User management
* Inventory tracking

## Technologies

* HTML
* CSS
* JavaScript

## Project Goal

The project was created as part of a university coursework focused on modern retail management systems and web technologies.
